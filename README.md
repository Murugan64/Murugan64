# 🎓 Final Year Project

## 🧠 VECTORAG — LLM & Vector-Based Retrieval System

My **Final Year Project** is an AI-powered application that uses **Large Language Model (LLM)** technology and **vector-based retrieval** to provide relevant responses from stored information.

### 🔹 Technologies Used

![TinyLLaMA](https://img.shields.io/badge/TinyLLaMA-LLM-blue?style=for-the-badge)
![Pytesseract](https://img.shields.io/badge/Pytesseract-OCR-green?style=for-the-badge)
![Vector Database](https://img.shields.io/badge/Vector%20Database-RAG-purple?style=for-the-badge)
![GitHub](https://img.shields.io/badge/GitHub-Version%20Control-black?style=for-the-badge)

### 🔹 Project Workflow

```text
Document / Image
       ↓
Pytesseract OCR
       ↓
Text Extraction
       ↓
Vector Database
       ↓
Relevant Information Retrieval
       ↓
TinyLLaMA LLM
       ↓
Generated Response
```

### 🔹 Key Areas

* 📄 Text extraction from documents/images using **Pytesseract OCR**
* 🔎 Storage and retrieval using a **Vector Database**
* 🧠 Response generation using **TinyLLaMA**
* 🔗 Retrieval-Augmented Generation (RAG) approach
* 📂 Source code managed using **GitHub**
